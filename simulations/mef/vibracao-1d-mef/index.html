Problema de Autovalor 1D - Vibração em Corpo Sólido (MEF)

Sobre o problema

Problema 5.2.6: Solução de problema de autovalor 1D - vibração em um corpo sólido. Este código resolve o problema de vibração livre de uma barra 1D usando MEF, calculando frequências naturais e modos de vibração através da solução do problema de autovalor.

Funcionalidades

  • Condições de contorno: Livre-livre, engastada-engastada, engastada-livre, engastada-apoiada
  • Propriedades variáveis: Constante, linear, parabólica, exponencial
  • Análises: Frequências naturais, modos de vibração, propriedades materiais
  • Casos pré-definidos: Barra de aço, barra de alumínio, coluna de concreto, barra composta
  • Solução analítica: Comparação com resultados analíticos para propriedades constantes

Equação diferencial

ρ(x)A(x) ∂²u/∂t² = ∂/∂x[E(x)A(x) ∂u/∂x], onde u é o deslocamento axial, ρ(x) é a densidade variável, A(x) é a área da seção transversal variável e E(x) é o módulo de elasticidade variável.

Problema de autovalor

K φ = λ M φ, onde K é a matriz de rigidez, M é a matriz de massa, φ são os modos de vibração e λ = ω² são os autovalores (ω é a frequência angular).

Solução analítica

Disponível apenas para propriedades constantes (E, ρ e A constantes). Para propriedades variáveis, apenas o MEF fornece a solução numérica.

Parâmetros

Disponível apenas para propriedades constantes
