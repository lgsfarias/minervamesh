Condução Transiente 1D (MEF)

Sobre o problema

Equação governante

Condução de calor transiente numa barra com condutividade constante por trecho, descontínua em x = L/2:

$$ \rho c_p\,\frac{\partial T}{\partial t} = \frac{\partial}{\partial x}\!\left(k(x)\,\frac{\partial T}{\partial x}\right) $$

com $k(x) = k_1 \ \ (x < L/2)$, $k(x) = k_2 \ \ (x \ge L/2)$.

Domínio

Barra de comprimento L, nₑ elementos lineares com um nó exatamente em x = L/2; tempo de 0 a t_max: $0 \le x \le L$, $0 < t \le t_{\max}$.

Condições de contorno

  • Extremidade esquerda (valor fixo no código): $T(0, t) = 0$
  • Extremidade direita (valor fixo no código): $T(L, t) = 1$

Condição inicial

Temperatura nula no interior da barra: $T(x, 0) = 0$, $0 < x < L$.

Método numérico

Método dos Elementos Finitos com elementos lineares e matriz de massa consistente, com k avaliado no centro de cada elemento; integração no tempo pelo método θ (θ = 0,5 é Crank-Nicolson, θ = 1 implícito, θ = 0 explícito), com um sistema linear resolvido a cada passo.

Solução de referência

Regime permanente analítico: o fluxo de calor é constante ao longo da barra, logo o perfil é linear em cada metade, contínuo em x = L/2,

$$ T_\infty(x) = \begin{cases} \dfrac{C}{k_1}\,x, & x < L/2 \\[6pt] \dfrac{C L}{2 k_1} + \dfrac{C}{k_2}\left(x - \dfrac{L}{2}\right), & x \ge L/2 \end{cases} \qquad C = \frac{2 k_1 k_2}{L\,(k_1 + k_2)} $$

de modo que a temperatura no meio da barra é $T_\infty(L/2) = \dfrac{k_2}{k_1 + k_2}$.
