Convecção-Difusão 1D Permanente (MEF)

Sobre o problema

Resolvemos o problema 5.2.4 (apostila) de convecção-difusão térmica unidimensional em regime permanente. A equação governante é:

-k d²T/dx² + ρcp u dT/dx = Q

Método utilizado

Método dos Elementos Finitos (MEF) 1D com elementos lineares. Inclui estabilização SUPG (Streamline Upwind Petrov-Galerkin) para problemas com alta convecção (número de Péclet elevado).

Parâmetros físicos

  • k: condutividade térmica [W/m·K]
  • ρcp: densidade × calor específico [J/m³·K]
  • u: velocidade de convecção [m/s]
  • Q: geração interna de calor [W/m³]
