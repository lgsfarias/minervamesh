MinervaMesh - Escoamento de Fluido 2D

Sobre o problema

Esta simulação modela o escoamento de um fluido incompressível em regime permanente através de um canal com uma obstrução circular. A formulação utilizada é baseada na Função Corrente ($\psi$) e Vorticidade ($\omega$).

Método Numérico

A discretização espacial é feita via Método dos Elementos Finitos (MEF) utilizando triângulos lineares. A malha é gerada estruturadamente e adaptada para contornar o obstáculo usando matplotlib.tri. O sistema é resolvido para encontrar o campo de velocidades (visualizado pelas linhas de corrente) e a vorticidade.
