Escoamento Potencial 2D

Sobre o problema

Resolvemos o problema de escoamento potencial incompressível e irrotacional em 2D. A equação governante é a Equação de Laplace para a função corrente ($\psi$):

$$ \nabla^2 \psi = \frac{\partial^2 \psi}{\partial x^2} + \frac{\partial^2 \psi}{\partial y^2} = 0 $$

Método utilizado: Método dos Elementos Finitos (MEF) com elementos triangulares lineares.

Parâmetros físicos:

  • $\rho$: Densidade do fluido [kg/m³]
  • $U_\infty$: Velocidade do escoamento livre [m/s]
  • $L, H$: Dimensões do domínio [m]
