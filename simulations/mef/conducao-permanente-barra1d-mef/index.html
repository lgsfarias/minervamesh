Condução Permanente 1D (MEF)

Sobre o problema

Equação governante

Condução de calor em regime permanente numa barra com geração interna uniforme Q e condutividade k:

$$ -k\,\frac{d^2 T}{dx^2} = Q, \qquad 0 \le x \le L $$

Domínio

Barra de comprimento L dividida em nₑ elementos lineares de tamanho uniforme: $h = L/n_e$.

Condições de contorno

  • Extremidade esquerda, temperatura prescrita: $T(0) = T_0$
  • Extremidade direita, temperatura prescrita: $T(L) = T_L$

Método numérico

Método dos Elementos Finitos (Galerkin) com elementos lineares: matriz de rigidez e vetor de carga montados elemento a elemento; condições de Dirichlet impostas por substituição das linhas correspondentes; sistema resolvido diretamente.

Solução de referência

Solução analítica obtida por integração direta da equação com as condições de contorno acima:

$$ T(x) = -\frac{Q}{2k}\,x^2 + C_1 x + T_0, \qquad C_1 = \frac{T_L - T_0}{L} + \frac{Q L}{2k} $$
